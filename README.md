# Library Book Search and Catalogue System

## Objective
To organize library books by Book ID and support adding,
searching, deleting and displaying book records.

## Data Structure
Binary Search Tree (BST).

## Technologies
- HTML
- CSS
- JavaScript
- Java
- Java built-in HTTP server

## Features
1. Add a book using ID, title and author.
2. Search for a book by ID.
3. Delete a book by ID.
4. Display books in sorted order.
5. View total book count.

## Core Concepts
- BST Insertion
- BST Searching
- BST Deletion
- Inorder Traversal

## Run the Project
From the project root folder:

    javac backend/*.java
    java -cp backend LibraryBookSearch

Open port 8080 in your browser.

## Note
The current version stores books in memory.
Records reset when the Java server restarts.
